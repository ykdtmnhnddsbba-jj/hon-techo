# 本の手帖

会社の書籍購入補助（月1万円）で買う IT・ビジネス書を、**読んだ後メルカリで高く売れるか**で選ぶための個人用サイト。

- 📚 候補ランキング：直近3か月に発売された本を「実質負担（Amazon価格 − 売却後の手取り）」が小さい順に表示。ネコポス可否・メルカリの売却実績・競合出品数つき
- 🧾 購入・売却記録：買った本の状態（読書中／出品中／売却済み）と売値を記録
- 💴 収支：月別の購入額・補助枠・手取り・実質負担
- 🔎 調査メモ：判定ルールと、新しい調査の頼み方

構成は他の手帖と同じ（単一 index.html、ビルドなし、GitHub Pages ＋ Google Drive 同期）。
候補データ `data/*.json` は Claude が調査して push する（手順は RESEARCH.md）。
